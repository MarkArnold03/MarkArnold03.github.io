KYH project, 2023

A banking app in ASP.NET Core MVC.

A school project at KYH where I built the core of a bank's internal system, from login and roles to customers and transactions.

Role
Solo developer
Period
April to June 2023
Stack
C#, ASP.NET Core MVC, EF Core, Identity, SQL Server, AJAX

What it does

  • Roles. ASP.NET Core Identity with separate admin and cashier roles.
  • Customers. Paginated customer search across the whole register.
  • Transactions. Transaction handling, with account history loaded over AJAX so pages stay fast.
  • Data. Entity Framework Core on SQL Server.
