Skolprojekt på KYH, 2023

En bankapp i ASP.NET Core MVC.

Ett skolprojekt på KYH där jag byggde kärnan i en banks interna system, från inloggning och roller till kunder och transaktioner.

Roll
Ensam utvecklare
Period
April till juni 2023
Stack
C#, ASP.NET Core MVC, EF Core, Identity, SQL Server, AJAX

Vad den gör

  • Roller. ASP.NET Core Identity med separata roller för admin och kassör.
  • Kunder. Kundsök med paginering i hela registret.
  • Transaktioner. Transaktionshantering, där kontohistoriken laddas med AJAX så att sidorna går snabbt.
  • Data. Entity Framework Core mot SQL Server.
